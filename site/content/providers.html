The Milestone 2 setup work adds guided destination choices. A preset is a configuration aid: it is not OAuth, automatic account creation or proof of provider acceptance. Use rtmps:// when your provider supports it.

Save privately, then verify

  1. Open Desktop setup and choose the intended destination.
  2. Copy the server URL without embedding the key, username or a credential-bearing query string. Enter the key only in its private field.
  3. Save settings, make a local audio/video clip, then start one deliberate broadcast.
  4. Confirm the intended channel or event on another device. Check audible sound and picture, then stop and verify output ends.

Provider eligibility, event visibility and ingest requirements can change. Consult the provider's dashboard rather than treating an old example URL as permanent.

Current boundaries

One configured destination is used at a time. These choices do not establish simultaneous multistreaming, browser-source integration, chat features or per-provider hardware qualification. Record exact source, device, provider and viewer outcomes for each claimed supported path.
