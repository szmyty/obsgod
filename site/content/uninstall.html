Inspect first

Use Decky's plugin controls for normal plugin removal. The optional retained Desktop tool has separate explicit scopes. From a reviewed current package, preview its inventory:

python3 uninstall.py --dry-run

Actual removal refuses active, unknown or busy output. Review the paths and explicit confirmation. Ordinary OBS, other plugins and shared dependencies are outside this tool's owned-data scope.

Choose the intended scope

CommandIntended effect in the candidate source
python3 uninstall.pyRemove the app and its Decky plugin through the supported local route. Preserve settings, state, cache, backups and media by default.
python3 uninstall.py --legacy-app-onlyRetire only owned obsolete Desktop app files and launchers. Preserve the active Decky plugin, shared settings/state/cache, backups and media. Close idle managed OBS explicitly before applying.
python3 uninstall.py --resetKeep the app/plugin installed and clear owned configuration, private managed OBS configuration, state and cache.
python3 uninstall.py --wipeFirst create and verify a private recovery TAR outside removal roots, then remove the app/plugin plus selected owned configuration, state, cache and backups. The TAR remains after wipe and can contain credentials. Minimal coordination metadata remains; media is a separate choice.
python3 uninstall.py --purge-settingsLegacy option: uninstall and remove settings/private managed OBS configuration without implying a complete state/backup wipe.

These are source-preview commands. Consult python3 uninstall.py --help from your exact installed package; older previews may expose fewer options.

Recordings require a separate choice

Recordings stay unless explicitly selected. Consult the exact candidate's --delete-recordings and repeatable --recording PATH help, then inspect the dry-run inventory before confirming. Changed, unrelated and unselected files must be preserved. A custom or shared recording directory is not an application-owned tree to remove recursively.

For wipe, --export PATH chooses a new archive in an owned private folder; the default is the XDG data sibling obsgod-wipe-exports. Failed or unsafe export stops before removal. Keep the archive private: it is not encrypted and does not belong in support reports. Recovery means inspecting its manifest in a new private staging directory and reinstalling a verified package, not automatic restoration or extracting over HOME. Deliberately remove the exact archive later if no recovery copy should remain.

If an installation is broken or Decky's local removal route is unavailable, use the reported recovery step. The tool must not replace that failure with broad privileged directory deletion.
