Install, check, then stream.

Install one standard Decky plugin, review dependency setup and configure privately in the panel.

Preview availability

This is a source and documentation preview. This page does not offer a qualified latest-version download. Follow the exact candidate source and qualification record for source/artifact revisions, checksums and limitations. Older archives do not contain newer source changes.

The supported target is SteamOS/Linux x86_64 on Steam Deck. Other platforms may compile, but compilation does not establish support. OBS is a managed graphical application, not a headless server.

Before installing

  • Install Decky Loader from its official project. In Gaming Mode, Decky appears in the ••• Quick Access panel, not as a normal Desktop application.
  • Use OBS Studio 28 or newer. Its WebSocket control server is bundled; do not add a second obs-websocket plugin.
  • The plugin lists compatible user-scoped OBS/GStreamer dependencies and asks before installing them. Install, Later, progress, cancellation and retry are explicit; loading the plugin does not authorize downloads.
  • Keep your existing installation and settings during an upgrade. Stop streaming and recording before changing application files.

Install a reviewed package

  1. Use the exact checksum-bound obsgod-decky.zip supplied with the review candidate. A GitHub source-code ZIP is not the built plugin. The final current-source download/test packet remains under qualification.
  2. Install through Decky's normal plugin installation controls. A separate Desktop application and updater are optional; the plugin is the primary update identity.
  3. Open ••• → Decky → @@DISPLAY_NAME@@ in Gaming Mode. Existing compatibility identifiers may still say OBSGod. Review dependency setup and choose Install or Later; declining keeps setup required.
  4. In Stream destination, enter the provider's RTMP(S) server and separate private key, then save. STEAM + X opens the keyboard. Saving never broadcasts and a saved key is never read back.

Optional Desktop Setup provides advanced profile, idle-media and storage controls. Its panel instructions explain how to open the bundled authenticated local page; a standard Decky installation does not create an Applications launcher. Keep that private page URL and all keys out of screenshots/logs. Retained Desktop archive installers apply only to their explicitly named historical source or optional Desktop installation.

Make the first audible clip

Choose Make 10-second test clip while playing game sound. This records locally and never broadcasts, so the streaming indicator may stay red. Inspect the clip in Videos/OBSGod in Desktop Mode and listen for sound. Confirm your microphone choice separately; it is off by default.

Then explicitly start streaming in Gaming Mode. On another device, open your channel and confirm picture and sound. A successful OBS command or green dot is not a viewer receipt. Use Stop and confirm the channel stops.
