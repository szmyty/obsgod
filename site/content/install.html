Start here

Install, check, then stream.

Use Desktop Mode for installation and private setup. Use Gaming Mode for the stream test.

Preview availability

This is a source and documentation preview. A reviewed Milestone 2 binary download is not available from this page. Follow the review PR for exact source, package revisions and checksums when a candidate is prepared. Older archives do not contain these new changes.

The supported target is SteamOS/Linux x86_64 on Steam Deck. Other platforms may compile, but compilation does not establish support. OBS is a managed graphical application, not a headless server.

Before installing

  • Install Decky Loader from its official project. In Gaming Mode, Decky appears in the ••• Quick Access panel, not as a normal Desktop application.
  • Use OBS Studio 28 or newer. Its WebSocket control server is bundled; do not add a second obs-websocket plugin.
  • The installer checks supported OBS and GStreamer capture dependencies, local Decky availability and the installation path. Read any failure and repair the named prerequisite before retrying.
  • Keep your existing installation and settings during an upgrade. Stop streaming and recording before changing application files.

Install a reviewed package

  1. Download the exact reviewed _linux_amd64.tar.gz candidate and verify its published checksum. Extract the whole archive.
  2. In the extracted directory, run the Desktop installer. Use a terminal if the launcher closes or opens as text: 
    python3 install.py --no-launch
    Run as your normal Deck user, without sudo. This installs the app and matching bundled plugin; it does not start a broadcast.
  3. Open the installed setup launcher. Enter the RTMP(S) server and key from your streaming provider, save, then finish setup. Keep the private setup URL and key out of screenshots and logs.
  4. Return to Gaming Mode and open ••• → Decky → @@DISPLAY_NAME@@. Some installation identifiers still say OBSGod during the compatibility transition.

Make the first audible clip

Choose Make 10-second test clip while playing game sound. This records locally and never broadcasts, so the streaming indicator may stay red. Inspect the clip in Videos/OBSGod in Desktop Mode and listen for sound. Confirm your microphone choice separately; it is off by default.

Then explicitly start streaming in Gaming Mode. On another device, open your channel and confirm picture and sound. A successful OBS command or green dot is not a viewer receipt. Use Stop and confirm the channel stops.
