Update the plugin through Decky

Check for updates compares the loaded plugin with verified published standard plugin metadata. It does not install anything or interrupt output. If no standard release is published, your installed plugin stays unchanged. A source PR is not a published release.

  1. Stop streaming, recording and replay, then wait for confirmed idle status. Inspect OBS first if output is unknown.
  2. Use Decky's plugin installation controls with the exact reviewed ZIP or official release URL.
  3. Verify the candidate version, source revision, checksums and qualification limits. Preserve settings and keys.
  4. After replacement, confirm the loaded plugin version, make an audible local clip, then perform an explicit viewer test.

A retained Desktop app is optional and managed separately. Its different version does not mean the plugin needs a paired repair, and plugin-only installations do not need a Desktop updater.

Optional Desktop recovery

Use a reviewed current recovery package only when you deliberately need the retained Desktop tool. It refuses active, unknown or busy output and protects a newer plugin from an ordinary downgrade. Deliberate recovery must name both the exact target and expected current plugin versions; consult that package's help.

Historical installers without the current recovery safeguards cannot be applied by the current updater. Automatic rollback needs the verified prior plugin version; an older Desktop archive is not necessarily a valid plugin backup. Keep the reported recovery state and use its specific instructions. Do not replace this refusal with arbitrary symlinks or broad privileged deletion.

Offline and failure behavior

An unavailable GitHub connection or rate limit should leave the installed version usable. Checking requires network access; local help, settings and supported local operations do not require a funding account. Broadcasting still requires your provider connection.

The owner is still choosing the final organization. Repository transfer and updater trust changes require a coordinated transition; redirects alone do not establish safe migration.
