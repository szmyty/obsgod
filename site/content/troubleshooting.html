Recover with useful evidence

Start with what OBS reports.

A timeout identifies a deadline, not the underlying cause. Keep the diagnostic message and installed versions.

Status means observation

StatusMeaning
Green · streamingOBS reports active output and recent byte progress. Confirm actual viewer picture and sound separately.
Red · stoppedOutput is confirmed inactive or the managed listener/process is absent.
Amber · connecting or stalledOBS is reconnecting or recent progress stopped.
Amber · check OBSOutput is unconfirmed and may still be live. Keep recovery Stop available and inspect the channel.

Status updates automatically; manual Refresh remains available. Repeated clicks do not establish new output transitions.

OBS startup or listener timeout

  • Copy the filtered console while still in the same Gaming Mode session. Switching to Desktop may end the process and change the evidence.
  • Inspect the managed OBS window for recovery/setup dialogs, launch/display errors or an unavailable authenticated listener.
  • Confirm OBS 28+ and bundled WebSocket are detected. Avoid launching a second unmanaged OBS against the same port.
  • Use the named repair path for detection or dependency failures. Increasing the timeout does not fix a wrong configuration directory.

Picture or sound is missing

A local clip tests capture without broadcasting. Play game sound and listen to the result. Microphone is separate and off by default. A selected output monitor may carry other apps; mute, device changes and zero volume need investigation.

Game-only may intentionally show fallback when the game is missing, ambiguous or unsupported. Entire-screen mode includes menus and must provide usable frames. Actual Gamescope and Flatpak versions matter; cloud native OBS tests do not prove device compatibility.

Report a useful problem

Use Copy console log, inspect it for private material, then include exact app/plugin/updater, SteamOS, OBS and Decky versions, capture/audio choices, the action, expected result and observed message. Never post a stream key, password or private setup link.
