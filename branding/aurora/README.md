# deckystream · selected aurora candidate

Open index.html for the standalone offline gallery. Extract deckystream-aurora-png.zip for ordinary PNG images. Transparent marks/wordmarks need a dark field; the light mark has a deliberate dark inset plate. The compact mark removes glow for small presentation. Monochrome is optional, not a Decky platform requirement.

The raster hero is one preserved image_gen output; vector geometry is separately authored by OpenAI Codex from the selected direction and is not an identical conversion. Exact source and output hashes are in aurora-manifest.json. Neither reproducible exports nor direction selection establish final rights/license, organization, publisher or actual device adoption. No approved Identity compiler, release or migration is claimed. The font notice is licenses/DejaVu.txt; no font binary is redistributed.

Regenerate with python3 scripts/generate-aurora-kit.py --raster; append --check for read-only drift verification. Old mint files/receipts are separate historical preparation and are never overwritten by this profile.
