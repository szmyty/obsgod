Decky Stream artwork

Start here: these are the viewable PNG previews of the current draft artwork. This page works offline as a single file; the images are embedded.

Draft review only. The current artwork is unchanged; final logo exploration and approval are separate. This is not an installer or a live software screenshot.

What to open

  • PNG: ordinary images for a browser or photo viewer. The separate decky-stream-png-previews.zip contains only PNGs and a plain-text guide; extract it first.
  • SVG: editable vector artwork; open in a browser or vector editor. Some photo apps cannot display it.
  • JSON / CSS: metadata and colors for tools; open in a text editor, not a photo viewer.
  • TXT / MD: guides and notices. HTML is this gallery. Open these source files in their matching apps rather than a photo viewer.
