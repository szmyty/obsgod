# Decky Stream repository artwork — draft

Start with index.html: it is one offline browser page with embedded PNG previews and file-type help. For a photo viewer, extract decky-stream-png-previews.zip; it contains ordinary PNG files plus START-HERE.txt. SVG, JSON and CSS files below are editable source/metadata, not photographs.

These are review candidates, not approved production branding or a live plugin replacement. Editable masters, actual generation methods and unresolved rights facts live in `.identity/candidates/`. The image-generation concept board is a reference; these SVG/PNG exports are generated from the editable SVG master.

The selected native Identity v1 web/GitHub dimensions inform the favicon and 1280×640 preview. README headers, avatars, wordmark, transparent/light variants and native Decky monochrome icon are product-specific draft exports, not native v1 profile outputs. Native `docs` produces document CSS. This local exporter is not Identity's production compiler. No PWA or generic social profile is claimed.

Regenerate with `python3 scripts/generate-brand-kit.py --raster --repository-assets`; append `--check` for read-only drift verification. The exact Inkscape and DejaVu Sans pins are in `.identity/toolchain.lock.json`; the separate font notice is `font-LICENSE.txt`. No font binary is redistributed. The manifest binds source and output bytes but is not human approval or a signature.
