01

Install the capture tools

OBS Studio and its GStreamer capture plugin install through Flathub into your home directory. Allow a few GB of free space and several minutes for the first download.

02

Connect your stream

Choose a destination guide, then copy its server URL and secret key from your own account. Your key stays on this Deck. Custom and local RTMP(S) servers work without another service account.

Official setup guide

Choosing a guide never changes your server or key. Change destinations only after closing idle managed OBS.

Leave the key blank to keep it only when the server URL is unchanged. A new server requires its own key.

Game only uses the selected game's capture source and shows your between-game screen when a game is unavailable. It never switches to entire-screen capture automatically. Change the mode while streaming and recording are stopped. Audio follows the selected system output and may include other applications.

Output is 720p with your game fitted inside the picture. HDR capture is not qualified; use SDR for the first test.

03

Verify the Gaming Mode toggle

The complete installer installs the app and its Decky plugin together. Keep the normal Steam client open in Desktop Mode so Decky's existing connection can handle installation.

Checking the Decky service…

If Decky is missing, use Decky's official interactive installation instructions, then return here and retry. OBSGod never installs Decky or makes privileged changes silently.

Local OBS connection

The managed instance uses an authenticated local control connection at 127.0.0.1:4457. Its generated password is separate from your stream key. Normal OBS scenes and passwords are separate.

Reading local connection details…

Testing only authenticates and reads state; it never launches OBS or starts a broadcast. Use Open managed OBS window above first if it is closed.

Change or recover the local control password

First use Close idle OBS / apply settings above. If authentication is broken, inspect and close the managed OBS window manually. Password changes are refused while OBS or its listener might be active.

A change updates both private managed settings. Afterwards, open managed OBS and test the connection to verify reconnection. Generating a password keeps it private; you do not need to copy it.

Secrets are stored as private local files, including OBS's own service settings. Never share those files or screenshots of your stream key.
