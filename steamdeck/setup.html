01

Install the capture tools

OBS Studio and its GStreamer capture plugin install through Flathub into your home directory. Allow a few GB of free space and several minutes for the first download.

02

Connect your stream

Copy the server URL and secret key from your Kick creator dashboard. Your key stays on this Deck. OBSGod also works with a custom RTMP(S) server.

When updating settings, leave the key blank to keep the saved key.

Output is 720p with your game fitted inside the picture. HDR capture is not qualified; use SDR for the first test.

03

Add the Gaming Mode toggle

The side-panel integration uses Decky Loader. If you do not have Decky, install it using its official instructions first.

Switch to Gaming Mode. Press ••• → Decky → ⚙ Settings → General and enable Developer mode. Under Developer → Install Plugin from ZIP, select the included obsgod-decky.zip.

Open a game, then ••• → Decky → OBSGod. First choose Make 10-second test clip. Watch the clip in Videos/OBSGod in Desktop Mode to check picture and audio. Then use Start streaming.

🟢 OBS streaming means OBS is sending data to your ingest server. Check your Kick channel on another device for the viewer-side picture and sound. 🔴 Stopped means the output is off. Amber means connecting, stalled or unconfirmed.
