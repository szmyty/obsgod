# Generic CLI snapshot contract

These archives contain the generic `obsgod` CLI. They are distinct from the
Steam Deck runtime, Decky plugin and one-click updater. They do not install OBS,
Flatpak, Decky, capture libraries or provider integrations. Cross-compilation is
not native-platform support or a published stable release.

The pinned GoReleaser 2.20.2 configuration builds the existing 20 target variants
with Go 1.27.4, explicit `CGO_ENABLED=0`, `-trimpath` and `-buildvcs=true`.
The workflow always uses
`release --snapshot --skip=publish,sign --clean`. No command here publishes,
deploys, configures accounts or broadcasts.

## Contents and notices

Each flat tar.gz/Windows ZIP contains exactly the executable, project LICENSE,
README, CHANGELOG, this guide as `GENERIC-CLI.md`, `THIRD_PARTY_NOTICES.md` and
`GO-NOTICES.json`. The full Go standard-library license and target-selected
modules' full upstream license texts are included. The union of the 20 targets
is a conservative notice superset; each archive's SPDX inventory
lists only actual linked modules. Package selection uses `go list -deps` with
the target GOOS/GOARCH/GOARM and `-mod=readonly`; it does not compile or add module
versions. Unloaded test/documentation-only graph entries are not redistributed.
No irrelevant Decky LGPL/source package or native capture payload is copied into
the generic distribution.

The prebuild helper verifies the pinned Go version and `go mod verify`, rejects
module replacements/missing licenses, and binds the license catalog to source
`go.mod`/`go.sum` and license hashes. Commit time supplies deterministic archive
and inventory timestamps; it is not an assertion about when a check ran.

## Audit and trust

From a clean committed source with the supported pinned development tools:

```sh
goreleaser release --snapshot --skip=publish,sign --clean
python3 scripts/generic-release.py audit \
  --revision "$(git rev-parse HEAD)" \
  --artifacts dist/snapshot --output dist/snapshot/supply-chain
```

The audit reads all 20 expected archives without extracting or executing them.
It verifies outer checksums, exact flat payloads, complete notices against the
selected source/tool/module cache, file/link/privilege/duplicate/expansion safety,
and each binary's Go build metadata. GOOS/GOARCH/GOARM, disabled CGO, toolchain and
linked module versions/checksums must agree. Go VCS metadata must identify Git,
the exact selected revision and `vcs.modified=false`; missing/dirty/different VCS
records are rejected. Snapshot version and embedded string presence bind the
application version separately. Trimmed Go records omit ldflags, so this static
version check does not prove the native runtime's reported values; the Linux
smoke checks those values by executing the CLI.
A partial
matrix, stale source, replaced module, missing license or conflicting artifact
fails closed. Native package-manager formats generated by nfpm are outside this
tar/zip audit and retain their own qualification work.

`dist/snapshot/supply-chain` contains an artifact-specific SPDX2.3 SBOM and
in-toto/SLSA-shaped unsigned provenance per archive, `SUMMARY.json` with actual
payload/binary/module hashes, and `AUDIT-SHA256SUMS` over these documents. Running
the audit twice must produce the same bytes. The workflow retains this compact
evidence and the snapshot checksum list through an Actions artifact; local ACT
delivery proves only its local artifact service.

These are **unsigned, self-reported inventories**. They establish neither an
authenticated publisher/trusted builder nor a SLSA level. A checksum is useful
only when compared with a trusted copy. The smoke test executes the selected
binary: run it only for your trusted source/build and audited artifact, not an
arbitrary download accompanied by an untrusted summary.

## Linux user-prefix check

The workflow uses the existing unprivileged fixture helper:

```sh
python3 scripts/run-user-tests.py --output-root /absolute/private/generic-smoke \
  -- scripts/generic-release.py smoke --artifacts dist/snapshot \
  --audit dist/snapshot/supply-chain/SUMMARY.json \
  --output /absolute/private/generic-smoke/results
```

Only the verified Linux amd64 archive is extracted into a new private temporary
directory by explicit regular-file writes. Its exact binary is installed into
that temporary user's `$HOME/.local/bin`; the test runs `version --json`,
`config path` and `api capabilities` without OBS/network credentials. It checks
the exact version/source and config location, then removes only its temporary
fixture. No existing installation, configuration or system package is changed.
The persistent receipt records actual UID/GID, archive/source and command scope.

For a manual generic installation, select a natively qualified artifact and verify
its checksums/notices and publisher through the approved channel before running
it. Extract into a new user-owned directory and copy the executable into your
user-owned bin directory. Keep the notices and archive-specific audit beside the
download. Set connection credentials through the documented private configuration
references; installing or inspecting configuration never starts OBS/broadcasting.

## Remaining qualification

Linux extraction/offline CLI proof does not establish OBS interoperability or
native Windows/macOS/BSD/arm runtime, installer/package-manager behavior or stable
support. Actual platform tests, required hosted CI/reviews, publisher/signing
policy, release notes and explicit release approval remain in the #46/#12 ledger.
Generic distribution preparation is not a new prerequisite for the compatible
Steam Deck preview or permission to replace its immutable review artifacts.
